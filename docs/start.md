# Kriegsspiel Table help

A table for Kriegsspiel practitioners, umpires and players alike: map, pieces, dice, ruler and turns, shared
live over the network or kept to yourself.

| I want to | Read |
|---|---|
| Run a game | [The umpire's guide](umpire-guide.md) |
| Keep my own map, study a scenario, watch a game | [The player's guide](player-guide.md) |
| Look up a key | [Keys and mouse](keys.md) |
| Bring a TTS module across | [Import a module](community-guide.md#import-a-tabletop-simulator-module) |
| Make pieces | [The piece studio](community-guide.md#the-piece-studio) |
| Share a pack or scenario | [Sharing](community-guide.md#share-packs-and-scenarios) |
| Write a script | [The scripting guide](scripting.md), then the [API reference](scripting-api.md) |

**Finding things.** The box at the top left searches all of help. The box at the top right finds words on this
page. Over a tool on the table, **F1** opens its section.
